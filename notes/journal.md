The purpose of this journal is to offer space for me to express what this project is (half-baked thoughts encouraged).

Essentially, I am trying to predict stocks in the S&P 500 using factor models, as well as testing how long each factor persists. 

I have only (nearly) completed the data layer, which has actually been very fun!! Little surprised at the amount of fun I've had just engineering the data layer.

As of now, the data layer fetches which tickers were in the S&P across time from Wikipedia (universe.py) as well as pricing data for each ticker (prices.py). Only one API is left to be built in prices.py; otherwise both .py files are complete.

Each file has test suites.
